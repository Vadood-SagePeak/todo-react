# Demo Task

## Request
Please review this repository and implement the following change:

Improve the new todo input experience on the main page.

Users should not be able to add a todo when the input is empty or contains only whitespace.

## What you should do
- Add validation for the new todo input
- Show a clear inline validation message under the input field when the value is invalid
- Disable the Add button when the input is empty or whitespace-only
- Keep the change visually clear on the main page so it is easy to notice in a demo
- Implement the smallest practical change within the current app structure
- Add or update tests if appropriate
- Run relevant checks if available
- Prepare the work as a reviewable pull request

## Pull request expectations
The pull request should include:
- a short summary of the change
- the files modified
- how the UI behavior changed
- tests or checks performed
- any assumptions or limitations

## Boundaries
- Keep the change small and practical
- Stay within the current app structure
- Do not perform major refactors
- Do not merge the pull request
- Human review is required before approval
